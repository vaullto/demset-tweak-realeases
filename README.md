# Demset Tweaks

## تحميل
**[⬇ Demset-Tweaks-Setup.exe](https://github.com/vaullto/demset-tweak-realeases/raw/main/Demset-Tweaks-Setup.exe)** — مثبّت صغير (أقل من 1 ميجا)، يحمّل البرنامج ويثبّته، ويسوي اختصار على سطح المكتب.

بعد التثبيت، البرنامج يتحدث لحاله من داخله.

ملاحظة: الويندوز ممكن يطلع تحذير SmartScreen لأن المثبّت مو موقّع رقميًا — اضغط "More info" ← "Run anyway".
